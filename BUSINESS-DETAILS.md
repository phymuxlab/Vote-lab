# Business details required before production

These values are intentionally not invented.

Set the following deployment variables:

- `NEXT_PUBLIC_BUSINESS_NAME`
- `NEXT_PUBLIC_CONTACT_EMAIL`
- `NEXT_PUBLIC_CONTACT_ADDRESS`

The legal pages currently render an obvious placeholder when these variables are missing. Do not launch a public production service with the placeholders.

Developer credit currently remains `MUXLAB`, matching the existing product credit in the project.
